# Evidencia insuficiente para validación integral

Fecha de cierre de la muestra: 2026-08-10.

Se examinaron **6 estudios publicados** contra todos los requisitos obligatorios, abriendo el texto completo y los materiales primarios disponibles. Sólo **1 estudio** cumplió conjuntamente: publicación persistente, datos brutos públicos con licencia, condiciones y resultado identificables, anclas sin ajuste retrospectivo, umbrales exactos y al menos un resultado publicado comparable.

Las **5 exclusiones** se distribuyen así:

| Motivo factual | Estudios |
| --- | ---: |
| anclas ausentes | 2 |
| sin datos brutos | 1 |
| archivo inaccesible | 2 |
| umbral ausente | 0 |
| resultado no comparable | 0 |
| licencia incompatible | 0 |

La muestra cerrada contiene únicamente E001, Krogslund, Choi y Poertner (2015). No se completó el cupo con candidatos débiles y no se ejecutó `fsqca-calibrador` durante la selección.

Con menos de tres estudios fuertes **no procede afirmar validación integral ni validación externa en varias replicaciones**. La evidencia sólo permite planificar una replicación individual del estudio incluido; las carencias de los otros candidatos deben tratarse como límites de evidencia, no como resultados favorables o desfavorables de la aplicación.
